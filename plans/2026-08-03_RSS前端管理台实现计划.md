# RSS 前端管理台实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 使用原生 HTML、CSS、JavaScript 构建由 Koa 同源提供的 RSS 单页管理台。

**Architecture:** `backend/public/` 保存静态页面；`koa-static` 在 API 路由前提供资源；浏览器 JavaScript 通过现有 REST API 管理平台、刷新缓存和展示聚合条目。动态内容全部使用 DOM API 写入，纯格式化函数可被 Node 测试导入。

**Tech Stack:** HTML5、CSS3、ES Modules、Koa 3、`koa-static`、Node.js `node:test`、Supertest。

## Global Constraints

- 不使用前端框架、构建工具、远程 CDN、远程字体或远程图标。
- 页面由 Koa 在 `/` 提供，API 与页面同源。
- 页面包含平台 CRUD、刷新结果、聚合条目和原始 XML 查看。
- 聚合数据只来自 `GET /rss/items`，浏览器不直接请求 RSS 地址。
- 动态 RSS 内容使用 `textContent`，禁止把原始 XML 注入 `innerHTML`。
- 保持现有 API、统一响应、404 和 Docker 数据持久化行为。
- 注释和文档使用中文，不自动 Push。
