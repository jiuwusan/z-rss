# Koa 后端初始化实现计划

> **执行要求：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 逐任务实施。每一步使用复选框跟踪。

**目标：** 在空的 `backend/` 中建立可启动、可测试的 Koa ES Modules 后端，并提供经典技术分层和健康检查示例。

**架构：** `src/app.js` 负责组装 Koa 中间件与路由，`src/server.js` 只负责监听端口。请求按 `route → controller → service → util` 流动，错误中间件统一处理异常，接口测试通过本机随机端口验证行为并主动回收服务连接。

**技术栈：** Node.js 22、npm、Koa、`@koa/router`、`dotenv`、Node.js `node:test`、Supertest。

## 全局约束

- 使用 ES Modules（`import/export`）。
- 采用 `routes / controllers / services / middlewares / utils / config` 经典技术分层。
- 首版只实现健康检查、统一响应、404、异常处理、环境配置和基础测试。
- 不接入数据库、鉴权、日志框架、参数校验框架和 RSS 业务接口。
- 代码注释和文档使用中文，不保留废弃代码或无用注释。
- 严格遵循 Red-Green-Refactor：先看到测试因缺少行为而失败，再写最小实现。
- 不自动 Push。

- `backend/package.json`：项目元数据、ESM 标记、启动与测试脚本、依赖声明。
- `backend/package-lock.json`：npm 依赖锁文件，由 `npm install` 生成。
- `backend/src/app.js`：创建并组装 Koa 应用。
- `backend/src/server.js`：启动 HTTP 服务。
- `backend/src/config/index.js`：解析环境变量并导出运行配置。
- `backend/src/routes/index.js`：聚合所有业务路由。
- `backend/src/routes/health.route.js`：声明健康检查路由。
- `backend/src/controllers/health.controller.js`：处理健康检查请求和响应。
- `backend/src/services/health.service.js`：生成健康状态数据。
- `backend/src/middlewares/error.middleware.js`：捕获并转换下游异常。
- `backend/src/utils/response.util.js`：构造统一成功和错误响应。
- `backend/tests/health.test.js`：验证健康检查接口。

```js
export async function startTestServer(app) {
  const server = app.listen(0, '127.0.0.1');
  await once(server, 'listening');
  return server;
}

export async function stopTestServer(server) {
  const closePromise = new Promise((resolve, reject) => {
    server.close((error) => {
      if (error) {
        reject(error);
        return;
      }
      resolve();
    });
  });

  server.closeAllConnections();
  await closePromise;
}
```

创建 `backend/src/middlewares/error.middleware.js`：

```js
import { createErrorResponse } from '../utils/response.util.js';

/**
 * 捕获下游异常并转换为统一错误响应。
 * @param {import('koa').Context} ctx Koa 请求上下文
 * @param {import('koa').Next} next 下游中间件
 */
export async function errorMiddleware(ctx, next) {
  try {
    await next();
  } catch (error) {
    const isHttpStatus = Number.isInteger(error.status)
      && error.status >= 400
      && error.status < 600;
    const status = isHttpStatus ? error.status : 500;
    const message = status === 500
      ? '服务器内部错误'
      : error.message || '请求失败';

    ctx.status = status;
    ctx.body = createErrorResponse(status, message);

    if (process.env.NODE_ENV === 'development') {
      console.error(error);
    }
  }
}
```

将 `backend/src/app.js` 更新为：

```js
import Koa from 'koa';
import { errorMiddleware } from './middlewares/error.middleware.js';
import router from './routes/index.js';
import { createErrorResponse } from './utils/response.util.js';

/**
 * 创建并组装 Koa 应用。
 * @returns {Koa}
 */
export function createApp() {
  const app = new Koa();

  app.use(errorMiddleware);
  app.use(router.routes());
  app.use(router.allowedMethods());
  app.use(async (ctx) => {
    ctx.status = 404;
```
